# Silicon Sample Megastudy
The goal here is to silicon sample the outcomes of Jan Pfanders megastudy using a small local base LLM. This is in the context of a silicon sampling experiment outcome prediction competition.

To do this, please do the following tasks:
1. [template creation](/docs/tasks/questionnaire_to_templates.md)
2. [silicon sampling](/docs/tasks/sampling_template_responses_with_local_model.md)
3. [data analysis](/docs/tasks/data_analyze_silicon_samples.md)
